# 卡牌大师（card_master）

让 N.E.K.O 的猫娘（YUI）**自主学习和练习各类卡牌游戏**——德州扑克、Kards、掼蛋。

装上这个插件后，YUI 可以创建虚拟牌局、发牌、出牌、计算胜率、获取出牌建议、自我对弈训练，还能查询 Kards 的真实规则和卡组检查。

---

## ✨ 功能特性

### 德州扑克（完整牌局模拟）
- **创建牌局**：2-10 人，自定义盲注和玩家，支持随机种子复现
- **完整流程**：翻牌前→翻牌→转牌→河牌→摊牌，下注/跟注/加注/弃牌/全下
- **牌型评估**：7 选 5 最佳牌型，支持任意 5/7 张牌
- **胜率计算**：蒙特卡洛模拟，支持 1-N 个对手
- **出牌建议**：综合胜率 + 底池赔率 + 位置，给出 fold/check/call/raise 建议及理由
- **自我对弈**：AI vs AI 对弈，YUI 可观察学习每步决策
- **下一手牌**：移动庄家位，连续多手牌

### Kards（真实规则学习辅助）
> 所有规则数据来自 Kards 官方 wiki（wiki.biligame.com/kards）和官方教程（decks.kards.com），不编造。

- **完整规则查询**：基本规则、指挥点系统、三条战线、卡牌类型、5种单位类型、学习路径
- **能力关键词**：20+ 个关键词解释（闪击、部署、亡计、守护、伏击、冲击、重甲、烟幕、压制、钳击、山地等）
- **国家特色**：9 个国家（5主要国 + 4盟国）的玩法风格和特色
- **卡组检查**：验证卡组是否合法（40张=1总部+39张，1主国+1盟国，国家有效性）

### 掼蛋
- 完整规则查询（牌型、逢人配、升级、进贡/还贡、抗贡等）

在 N.E.K.O 插件市场搜索 **卡牌大师** 或直接打开：

| 工具 | 作用 |
|---|---|

## 🔒 安全与设计

- **纯本地模拟**：所有牌局在本地内存中运行，不联网、不涉及真实金钱
- **牌局状态不持久化**：插件重启后牌局丢失（属预期，每次对话可新开）
- **Kards 规则来源可追溯**：全部来自官方 wiki，不编造机制
- **蒙特卡洛可复现**：支持 seed 参数，相同种子产生相同牌局
